## 전수 테스트에서 나온 결함

| # | 결함 | 상태 |
|---|---|---|
| D2 | `post-reply-ai-recommend` **100% 500** — 골든셋 최다 POST(24건) | **해소** |
| D1 | pre-handler 오류 봉투가 129경로에서 구를 벗어남 | **P6 선행 과제**(분석만) |
| D3 | 부정리뷰 스케줄러 시각 의존 500 | 구와 코드 동일 — **회귀 아님** |

**D2 는 서비스 코드가 아니라 엔티티 ID 의 JVM 타입 문제였다.**
구 `val id: Long` 은 원시형 `long` 으로 컴파일되는데 신은 래퍼 `Long` 이었다.
Spring Data 는 **원시형일 때만 `0` 을 새 엔티티로 본다** → `persist` 대신 `merge` 로 빠져 참조가 끊긴다.
46개 엔티티 전수 대조 후 20개를 원시형으로 되돌렸다(1개는 구가 nullable 이라 래퍼가 맞다).
라이브 A/B 로 500→200 확인, 골든 24건 재발사 24/24 일치.
